# Guide rapide — Comptable

## Tâches quotidiennes

1. Enregistrer les encaissements et les paiements.
2. Suivre les débiteurs et relances.
3. Générer les reçus et suivre les soldes.
4. Vérifier les dépenses et le journal de caisse.
5. Préparer les états financiers de l’école.

## Accès et limites

- Aucune suppression de paiement.
- Non autorisé à modifier les notes ou les bulletins.
- Le reverse reste réservé au directeur, avec motif obligatoire.
