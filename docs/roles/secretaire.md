# Guide rapide — Secrétaire

## Tâches quotidiennes

1. Gérer les dossiers élèves et responsables.
2. Enregistrer les inscriptions et réinscriptions.
3. Suivre les absences et les justificatifs.
4. Préparer les documents administratifs.
5. Soutenir la gestion administrative de l’école.

## Accès et limites

- Peut gérer les dossiers élèves et responsables.
- Peut préparer les certificats et informer les familles.
- Ne peut pas accéder au module finance ni modifier les notes.
