# Guide rapide — Super administrateur

## Tâches quotidiennes

1. Gérer la plateforme et les écoles.
2. Valider les demandes d’accès et les invitations.
3. Contrôler les interventions école par école.
4. Vérifier les opérations critiques et les journaux d’audit.

## Accès et limites

- Accès global interdit sans intervention active.
- L’accès aux données d’une école est strictement limité à l’école sélectionnée dans l’intervention.
- Les actions sont journalisées et auditées.
